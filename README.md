# 📚 StudyStack

A simple full-stack study management web application that helps students organize subjects, track study sessions, monitor progress, and manage their study activities in one place.

## 🌐 Live Demo

🔗 https://studystack-stqz.onrender.com

## 📂 GitHub Repository

🔗 https://github.com/Jebastin20/StudyStack

---

## ✨ Features

- 🔐 User Registration & Login
- 📚 Subject Management
- ⏱️ Study Session Tracking
- 📊 Dashboard with Study Statistics
- 🔥 Study Streak Tracking
- 🔔 Notifications
- 👤 User Profile
- 🖼️ Profile Picture Upload
- 🌙 Dark / Light Mode
- 📱 Responsive UI
- 🔒 JWT-based Authentication
- ☁️ Cloudinary Image Storage
- 🍃 MongoDB Database
